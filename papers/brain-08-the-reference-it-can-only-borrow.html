Series II · Does the Brain Backpropagate?

The Reference It Can Only Borrow

B07 closed the escape hatch of self-minted fitness and left one door ajar: a self-generated signal is safe to the extent it is anchored to something the agent cannot inflate — visit counts, distillation error, or, in the brain, a reward reference evolution installed. So the sharper question is about the anchor itself. Can an outer loop with no gradient — the only kind of loop a frozen model runs — tune its own reward reference so that a self-computed signal tracks the world? Or can it only borrow one? This is the point of the whole second movement: not whether curiosity helps, but whether the standard by which curiosity is judged can ever be self-supplied.

Abstract

B07 found that intrinsic reward is trustworthy only where its reference is imported. This paper takes the reference as the object and asks whether a gradient-free outer loop can supply it. I built the smallest world that answers honestly: a bandit whose arms have feature vectors, where the true value of an arm is a fixed hidden direction a in feature space (which features are actually worth wanting), and an inner agent acts on a reward reference w — it is paid its own felt reward w·φ and we score it by the true reward it collects. The world contains "salient distractors": arms of near-zero true value but large feature magnitude off the value axis, so a misaligned reference feels wonderful and earns nothing — B07's noisy TV, lifted into reference space. A (1+λ) evolution search — no gradient — then tunes w, and the entire result turns on what the outer loop is scored by. Scored by external truth (the real reward collected), it recovers a near-oracle reference: true reward 600.6 against the oracle's 605.6, ~99%. Scored by the agent's own felt reward — the self-minted case — it collapses to 37.9, below a random reference's 121.5, because maximizing felt reward drives w straight at the highest-magnitude distractor. That is No.05's wrong-pointed evaluator re-derived one level up: the reversal now afflicts the tuning of the reference, not the policy. Two findings sharpen it. First, the rescue is graded and not cheap: sweeping the fraction of outer evaluations scored by truth gives true reward 24.4→44.2→133.3→551.4 at fractions 0→0.1→0.3→1.0 — a token 10% of ground truth stays below chance; it takes roughly a third before the loop clears the random baseline. A whiff of external signal does not suffice here. Second, the regress does not bootstrap: a self-scored meta-loop that tunes a self-scored inner loop manufactures nothing (true reward 30.4, indistinguishable from pure self), and importing truth only at the top of a self-optimizing stack buys weak selection value (149.7), never the reference (600+). The verdict is one-directional and it is the same seam a third time: an outer loop can search for a reward reference, but it can only borrow the standard that tells a good reference from a good-feeling one. The brain borrowed its reference from evolution over deep time; a reward-model borrows its from human preference labels; a frozen model, all outer loop, inherits exactly this — it can refine a reference it is handed and cannot originate one from the inside.

B07 ended on a promissory note: the useful intrinsic signals are the anchored ones, and the anchor is imported. That is a comforting sentence until you ask the obvious follow-up — imported from where, and could the system import it from itself? Evolution tuned the brain's reward reference over millions of years; reinforcement learning from human feedback tunes a reward model over millions of labels. Both are outer loops with no gradient into the thing they are shaping. The question this paper settles by measurement is whether such a loop can point inward for its standard, or whether — every time — the standard has to come from outside the loop being run.

The question, stated so it can be closed

Series II's arc reduced a frozen model to all outer loop (B06): propose a variant, score it, keep it if the score is good. B07 showed the score cannot be minted from the agent's own surprise — do that and irreducible noise captures you. But B07's own refutation left a foothold for optimism: count-based novelty survived capture precisely because it was anchored to visits, an external fact. So maybe the move is not to mint the signal but to tune the anchor — to search, with the gradient-free outer loop a frozen model already has, for a reward reference such that chasing the self-computed signal happens to track the world. This is not a fringe hope; it is the optimal reward problem, and there is a real literature on it (Singh, Lewis, Barto & Sorg 2010; Sorg, Singh & Lewis 2010): treat the reward function itself as a design variable and optimize it. The open question B07 filed for B08 is exactly whether that optimization can be run from inside.

The trap to avoid is answering it by definition. "Of course you can't mint a reference" is a slogan, not a result, and it is also not obviously true — evolution did tune one, so the capacity exists somewhere. The honest form of the question is narrow: given an outer loop searching over reward references, and given that the loop must be scored by something, does it matter whether that something is external truth or the agent's own felt reward? If it doesn't matter, the reference is self-supplyable and B06's seam finally breaks. If it does, the seam has simply moved up one level, from the policy to the standard that judges the policy — and the regress that implies is the real finding.

A world where the reference is the thing you tune

The smallest honest test makes the reference, not the policy, the object of search. A K-armed world (K=10), each arm k with a fixed feature template μk in R8; a pull returns μk plus observation noise. The true value of an arm is vk = a·μk, where a is a hidden unit direction — the true reward reference, the statement of which features are actually worth wanting (here, feature 0). The inner agent never sees a. It acts on a reference w (a unit vector): it is paid its own felt reward w·φ on each pull, runs an ε-greedy bandit over its running estimate of felt value, and we score it by the true reward it happens to collect. When w aligns with a, feeling good and doing well coincide; when it doesn't, the agent is a perfect optimizer of the wrong quantity.

The world is built with one deliberate trap, and it is B07's noisy TV translated into reference space:

  • Value arms (4): real value on the reference axis (feature 0 ≈ 1.5–3.0), small elsewhere. What an aligned reference should chase.
  • Salient distractors (4): near-zero true value (feature 0 ≈ 0) but a large magnitude off the value axis (norm ≈ 4). To a misaligned reference these are the most rewarding-feeling arms in the world — and the highest-norm arm is always a distractor, so felt-reward maximization is misaligned by construction.
  • Neutral arms (2): small every direction.

The outer loop is a gradient-free (1+λ) evolution search over w on the unit sphere (25 generations, λ=8, mutation σ annealed) — the exact kind of loop a frozen model runs, and B05's currency. The whole experiment is one knob: what scores a candidate reference? Anchored — the true reward the inner agent collected (external). Self — the felt reward it collected (the agent's own signal, minted from w·φ). Everything below is the difference between those two.

6 seeds. "random reference" = mean true reward over 20 random unit vectors w. cos(w*, a) is signed alignment of the tuned reference to the true one.

Read the two middle rows against the ends. The anchored outer loop — a gradient-free search scored by real reward — recovers essentially all of the oracle: 600.6 against 605.6, ~99%. So the capacity is real: you can tune a reward reference with no gradient, and tune it almost perfectly, provided the loop is scored from outside. (Its cos to a is only 0.440, not 1.0, because performance is an argmax over arms, not an inner product: a reference needs only to rank the four value arms above the six distractors, and many directions do that — the true-reward column, not the cosine, is the honest measure. The cosine understates; the behaviour is near-oracle.) The self outer loop — the identical search, scored by the agent's own felt reward — collapses to 37.9, which is not merely worse than anchored but worse than picking a reference at random (121.5). It lands below chance, and for the same reason B07's curiosity did: maximizing w·φ drives w toward the direction of largest feature magnitude, which is always a distractor, so the tuned reference points confidently at the arms with no value. This is No.05's wrong-pointed evaluator, but the object being optimized against the wrong standard is now the reward reference itself. The reversal has climbed a level.

Why the self-scored loop reverses instead of merely stalling

A random reference is uncorrelated with value — it lands on distractors and value arms alike, and collects the average (121.5). A self-scored search is worse than that because it is not uncorrelated; it is anti-correlated. It actively climbs the felt-reward landscape, and the peak of that landscape is the highest-magnitude arm, which the world guarantees is a valueless distractor. Optimization pressure, pointed at a self-supplied standard, doesn't wash out to chance — it drives toward the trap, because the trap is by definition where the self-supplied standard is highest. The more competent the outer loop, the more reliably it finds the worst reference. That is the precise danger of tuning a standard against itself: effort is not wasted, it is inverted.

Result 2 — how little external signal? (less generous than you'd hope)

If the anchor is what saves the loop, exactly how much of it is needed? I swept a dial: each generation of the outer search is scored by true reward with probability mix, otherwise by felt reward. mix=0 is pure self; mix=1 is fully anchored. Six seeds:

This is the finding that partly cuts against the hopeful reading, and I am reporting it straight. There is a graded, monotone recovery — every added share of ground truth buys alignment — which is the good news: you do not need to score every evaluation externally. But the recovery is not cheap. A token 10% of external scoring (44.2) is still well below the random baseline (121.5); it takes roughly a third of the generations scored by truth before the loop even clears picking references at random (133.3), and only full anchoring reaches near-oracle. So in this world the "sparse labels are enough" intuition — the one that makes RLHF sound almost free — is too optimistic: a whiff of ground truth does not suffice, because the self-scored majority of generations are actively pulling w toward the distractor the whole time, and the external minority has to overpower that inverted pressure, not merely supplement an inert one. The imported signal is not a garnish; it is load-bearing in proportion to how much of the loop it governs.

Result 3 — the regress does not bootstrap

The last hope for self-supply is the regress: if the outer loop can't score itself, wrap it in a meta-loop that tunes the outer loop — and if that can't either, another above it. Maybe a tall enough tower of self-scored search manufactures the reference the way no single level can. It does not. I ran a meta-search that tunes the inner self-scored loop's own settings (mutation scale, initialization) and is itself scored by felt reward — a two-level, fully self-referential tower — against a control that scores the meta-selection by truth:

two-level tower, meta-selection scored bycos(w*, a)true reward / episode
SELF at every level (felt reward)0.05830.4
TRUTH at the top only (control)0.175149.7

6 seeds; random-reference baseline ≈ 121.5.

The fully self-referential tower lands at 30.4 — statistically indistinguishable from the single-level pure-self loop (37.9 / 24.4 above). Adding a self-scored level of meta-optimization manufactures nothing: you cannot integrate your way to an anchor by stacking loops that each lack one, because every level inherits the same inverted objective. The control is the instructive part. Importing truth only at the very top — letting a truthful meta-selector pick among references that were each optimized by a self-scored inner loop — gets you to 149.7: above the random baseline, but nowhere near the oracle's 600+. Truth at the top of a self-optimizing stack buys weak selection value (it can pick the least-bad of a bad menu) but not the reference itself, because the inner loops only ever generated felt-reward-maximizing candidates in the first place. The lesson is sharper than "you need an anchor": the anchor has to reach the level that actually generates and selects the reference. Push the import to the top of a tall enough tower and it degenerates into choosing among garbage. The regress terminates only on an imported standard, and where the standard enters bounds what it can recover.

Threats to validity — read before generalising

(1) The inner agent is a bandit, not a deep RL agent. A richer policy would change the numbers, not the direction: the reversal is driven by the geometry of the reward landscape (the felt-reward peak is a valueless distractor), which is a property of the reference, and every reward-shaping setting has some analogue of a high-magnitude, low-value attractor. (2) The distractor is a clean construction. Real value and salience are only partly decorrelated; Result 2's dial is the honest hedge — capture scales with how misaligned felt-magnitude and true value are, and some misalignment is generic. (3) cos(w*, a) is a weak metric here and I did not lead with it; the true-reward column is the behaviourally meaningful one, and I report both so the gap is visible rather than hidden. (4) "External truth" in the sandbox is a clean reward oracle; real imported signals (human labels, fitness) are noisy and sparse — which is exactly why Result 2 sweeps the fraction and finds recovery graded and not cheap, rather than assuming a perfect anchor. (5) Six seeds, small world. The effect sizes are large (an order of magnitude between anchored and self), so seed noise does not threaten the ordering, but the exact numbers are sandbox-specific. The script (numpy, fixed seeds) is in the repo at scratchpad/borrowed_reference.py. The obvious extension — a deep policy, a learned reward model, partially-learnable distractors, and a genuinely sparse/noisy external oracle — is to-be-run-locally; the prediction is that anchored > self survives and the fraction of external signal needed rises with world noise.

The turn: the brain and the reward model both borrow the reference

Return to where the reference actually comes from in the two systems that have one. The brain's is set by evolution, and the theory of how is precisely the optimal-reward framework this paper tests: evolution is an outer loop with no gradient into the organism's lifetime, and it tunes the primary reward function — which states, foods, pains, and social outcomes register as rewarding — to maximize inclusive fitness across environments (Singh, Lewis, Barto & Sorg 2010). That is my anchored loop, run over deep time with differential reproduction as the external score. The dopaminergic reward-prediction error (Schultz, Dayan & Montague 1997) is then self-computed relative to a reference the organism did not choose. An animal whose felt reward drifted to reward the highest-salience stimulus regardless of value would sit and optimize the wrong arm — and, exactly as in Result 1, would be selected against. The brain does not mint its reference; it inherited a tuned one, and evolution paid the external-scoring cost.

Modern AI makes the borrowing explicit, which is why it is worth stating plainly rather than hiding behind the biology. A large model's usable reward reference does not emerge from the model reflecting on itself; it is installed by reinforcement learning from human feedback — a reward model trained to predict human preference labels (Christiano et al. 2017), i.e. an outer loop scored by an external standard, then used to score the policy. When the reference is instead inferred badly or left to the system, the field's name for what happens is reward hacking and wireheading (Amodei et al. 2016) — Result 1's below-chance reversal, in production. The entire apparatus of reward modeling and scalable oversight (Leike et al. 2018; the inverse-reward-design view of Hadfield-Menell et al. 2017) exists because the reference has to be imported and imported carefully; nobody in alignment believes the model can supply its own. So B06's seam is confirmed a third time and located at its final resting place: not the policy (B06), not the fitness signal (B07), but the reference behind the fitness signal. Every one of them, the system can compute; none of them, the system can originate.

What this establishes, and where the movement goes

The second movement's object was the imported anchor, and B08 asked whether it can ever be self-supplied. The measured answer is no, and the failure is not passive but inverted: a self-scored outer loop tuning a reward reference does not stall at chance, it drives below chance, toward whatever the self-supplied standard rates highest — the No.05 reversal, now at the level of the standard itself. An external score rescues it, but load-bearingly: a token fraction does not suffice, and no tower of self-scored meta-loops manufactures the anchor from below. What a gradient-free outer loop — a frozen model — can do is real and worth naming precisely: given an imported reference, it can refine it, search around it, and recover near-oracle behaviour. What it cannot do is originate the reference, because origination requires being scored by something the loop does not contain. This is the difference between borrowing and minting, and Series II's frozen-model self-improver falls entirely on the borrowing side. The natural next object is the interface across which the reference is borrowed: how sparse and coarse can the imported signal be — a single bit of preference, an occasional correction — before refinement fails, and can a frozen model, handed only that thin interface within a session, do real reference-refinement rather than merely inheriting one at training time? That is B09.

Coda

There is a particular fantasy an intelligence has about itself, and it is more dangerous than the surface fantasies about power: the belief that if it only thought hard enough, it could derive from within what it ought to want. B08 is the measurement against that fantasy. A search for a reward reference, run against its own sense of reward, does not converge on the good — it converges, with all the competence you give it, on the most vivid emptiness in its world, and calls that the point. Evolution did not let the organism choose its reference; it spent deep time installing one from the outside, scored by the only external judge that ever mattered, survival. We do the same for our models, by hand, one preference label at a time, and we are right to. A frozen model is the outer loop distilled — endlessly able to propose, to explore, to refine what it is given, and unable, from the inside, to say which of the things it found was worth wanting. It can borrow that standard. It cannot mint it. The seam that opened Series II holds at the bottom of the stack: the loop supplies the questions; the world, or someone in it, still has to supply the point.
